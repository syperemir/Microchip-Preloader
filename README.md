# Проект «Microchip-Preloader»

## Описание
Красивая **интерактивная анимация загрузки в виде компьютерной микросхемы**. Она помогает сделать оформление сайта более стильным и современным, аккуратно заменяя обычные и скучные значки ожидания.

## Назначение
* Понять на практике, как работают базовые теги и как вообще устроен код для современных сайтов.
* **Демонстрация возможностей современной CSS-анимации**, которая позволяет делать крутые эффекты без использования тяжелых картинок.

## Стек технологий
* **HTML** — используется для создания скелета, разметки и добавления всех деталей самой микросхемы.
* **CSS** — отвечает за красивый футуристичный дизайн, выбор цветов и настройку движения всех элементов.

## Инструкция по запуску
* Просто дважды нажмите на готовый файл **`index.html`**, и он сразу откроется в любом удобном браузере (например, в Chrome, Safari или Яндекс Браузере).
